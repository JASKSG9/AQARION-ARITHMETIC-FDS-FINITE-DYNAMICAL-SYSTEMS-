Proof sketch for rank formula: The image of D is spanned by the observable components that leak. The rank equals the number of observable blocks minus the number of connected components of the block overlap graph, whose vertices are the blocks of Π and where (Bᵢ,Bⱼ) is an edge iff ∃ x ∈ Bᵢ with T(x) ∈ Bⱼ. This is a universal structural invariant for all finite deterministic systems.

Theorem 1 (Universal Observable Obstruction). D_Π = (I-P_Π) K P_Π = 0 ⇔ K(Im P_Π) ⊆ Im P_Π. Theorem 2 (Exact Rank Formula). rank(D_Π) = m - c, where m = |Π| and c = number of connected components of the block overlap graph.

Nilpotency proof: Since D = (I-P)KP and P(I-P)=0, we have D² = (I-P)KP(I-P)KP = 0.

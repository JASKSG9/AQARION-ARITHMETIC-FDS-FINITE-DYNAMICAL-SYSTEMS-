CORRECTED BRIDGE-COST PROOF


Let G_R have one vertex for each nontrivial cycle and one vertex for each support-meeting partition block.


Join C_j to B iff B ∩ C_j is nonempty.


For each support block B let


t_B = number of nontrivial cycles meeting B.



Then


t_B <= |B ∩ S|,



so


sum_B (t_B - 1) <= b.



Also


|E(G_R)| - q = sum_B (t_B - 1).



Every H_T hyperedge lies inside a single connected component of G_R, hence


c(G_R) <= c(H_T).



Since G_R has q+r vertices,


|E(G_R)| >= q+r-c(G_R).



Therefore


b >= r-c(G_R)
  >= r-c(H_T),



and hence


BOXED:
b + c(H_T) >= r.



Consequently


BOXED:
d_T(R) <= s-r.



Thus the universal multi-cycle bound survives, but the component-count proof must use an inequality rather than equality.

SETTING


Let T have r nontrivial cycles C_1,...,C_r with support S and |S|=s.


For a partition R define


B_S(R) = {B in R : B ∩ S != empty},
q = |B_S(R)|,


b(R) = s-q
= sum_{B in B_S(R)} (|B ∩ S|-1).


Let H_T(R) be the support transition hypergraph used in HYPERGRAPH-001, and let c(H_T(R)) denote its number of connected components.


STRUCTURAL DEFECT IDENTITY


d_T(R) = q - c(H_T(R))
= s - b(R) - c(H_T(R)).


NEW CYCLE-BLOCK INCIDENCE GRAPH


Construct G_R with:




one vertex for each nontrivial cycle C_j;


one vertex for each support-meeting partition block B;


an edge C_j--B iff B ∩ C_j is nonempty.




Every collection of original blocks meeting the same cycle lies in one connected component of H_T(R), because successive T-translates connect the blocks containing successive points of that cycle.


Conversely, every H_T hyperedge connects blocks through cycle labels already present in the transported source block.


Therefore


c(G_R) = c(H_T(R)).


EDGE COUNT


If t_B is the number of distinct nontrivial cycles meeting B, then


t_B <= |B ∩ S|,


hence


sum_B (t_B-1) <= sum_B (|B ∩ S|-1) = b.


But


|E(G_R)| - q = sum_B(t_B-1).


Since G_R has q+r vertices and c(H_T(R)) components,


|E(G_R)| >= q+r-c(H_T(R)).


Therefore


b >= r-c(H_T(R)),


so


BOXED:
b + c(H_T(R)) >= r.


UNIVERSAL MULTI-CYCLE BOUND


Using d_T = s-b-c,


BOXED:
d_T(R) <= s-r.

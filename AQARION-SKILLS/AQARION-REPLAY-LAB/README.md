# AQARION Replay Lab

> **Can you replay this claim—and can its evidence survive nearby wrong versions of the claim?**

AQARION Replay Lab is a research prototype for replayable mathematical, computational, and AI-assisted claims.

It records:

1. What was claimed.
2. The exact domain and carrier.
3. Which fixture was used.
4. Which verifier ran.
5. What facts were observed.
6. What verdict the evidence is allowed to support.
7. Which nearby invalid claims are rejected.

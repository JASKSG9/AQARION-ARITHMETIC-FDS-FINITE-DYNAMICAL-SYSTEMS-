1. Live Spectral Replay

This browser constructs the actual finite matrices:

D = (I - P) K_s P

It then computes the reduced Gram matrix:

G_numeric = U^T D^T D U

Separately, it constructs the closed-form target:

G_closed = [r(k-r)/k^2] (2I - S - S^-1)

Here (r = s \bmod k). All computations are browser JavaScript using IEEE-754 Float64 arithmetic.

Allowed values: 1 through 8. The special m = 2 doubled-edge case is handled explicitly.
Allowed values: 2 through 8. Total carrier size is n = m × k.
Allowed values automatically update to: 0 through n - 1.
This is not user-editable.

3. The m = 2 regression control


      

        The earlier bug was treating the two-block cycle as though it had one
        edge in each direction but only one accumulated off-diagonal weight.
      


      

        The correct circulant difference operator is:
      


      L_cyc = 2I - S - S^-1

      

        At (m=2), (S=S^{-1}), so:
      


      
L_cyc(2) = 2I - 2S

L_cyc(2) = [[2, -2],
            [-2, 2]]
      

      

        The incorrect simple-edge matrix is:
      


      
WRONG = [[2, -1],
         [-1, 2]]
      

      

        This app accumulates both cyclic neighbor contributions. It does not
        overwrite one with the other.

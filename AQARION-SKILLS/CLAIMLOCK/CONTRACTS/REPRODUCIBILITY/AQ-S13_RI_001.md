AQARION MINIMAL REPRODUCIBILITY INVARIANTS


Status: FROZEN DESIGN

Mode: EXACT · ADVERSARIAL · NO PROMOTION


RI-001 — Artifact existence is not execution


[
\text{ArtifactExists}
\neq
\text{ArtifactExecuted}.
]


A file's presence in a repository does not establish that it is reachable, importable, invoked by the workflow, or successfully executed.



RI-002 — Execution is not reproduction


[
\text{ArtifactExecuted}
\neq
\text{ResultReproduced}.
]


Successful process termination does not establish that the intended cases, computation, fixtures, or evaluation path were exercised.



RI-003 — Expected is not observed


[
\text{ExpectedOutput}
\neq
\text{ObservedOutput}.
]


A declared expected result MUST NOT populate an observed-result field.


Observed values require an actual recorded execution.



RI-004 — Same-route replay is not independent verification


[
\text{Replay}
\neq
\text{IndependentVerification}.
]


Re-executing the same implementation against the same expected formula may reproduce a shared implementation error.


Independent verification requires a materially independent route.



RI-005 — Successful output is not semantic coverage


[
\text{ProcessSuccess}
\neq
\text{ClaimResponsibilityExercised}.
]


A harness may terminate successfully while failing to exercise one or more responsibilities that the claim states it verified.


Such a condition is classified as:


[
\boxed{\text{SILENT_CERTIFICATION_FAILURE}}
]



RI-006 — Verified computation is not proof


[
\text{COMPUTATIONALLY_VERIFIED}
\neq
\text{DERIVED}
\neq
\text{LEAN_CERTIFIED}.
]


No computational receipt may be promoted to mathematical proof merely because it is deterministic or reproducible.



RI-007 — Blocked is not false


[
\boxed{\text{BLOCKED}\neq\text{FALSE}}
]


A claim may be mathematically unresolved, computationally supported, and promotion-blocked simultaneously.



RI-008 — External precedent is not theorem transfer


[
\boxed{
\text{EXTERNAL_CORROBORATION}
\neq
\text{INTERNAL_DEPENDENCY}
}
]


Literature may motivate architecture or corroborate a result without becoming a logical dependency of the AQARION theorem.



RI-009 — A formal build is not necessarily the intended theorem


A theorem receipt is semantically valid only if the compiled proposition matches the declared formal target.


Therefore:


[
\boxed{
\text{LeanCompiles}
\neq
\text{FormalTargetMatched}
}
]


A proposition such as True cannot discharge an obligation for a nontrivial K2R construction merely because it compiles.



RI-010 — Reproducibility requires a contract


For executable claim C, define:


[
\mathcal R(C)=(R,A,E,I,T,O,V,G)
]


where:




R: source/root identity,


A: artifact identity,


E: execution environment,


I: deterministic input manifest,


T: expected specification and tolerance,


O: observed execution output,


V: verification route and independence class,


G: governance disposition.




A claim is replayable only when all required contract coordinates are present.


A claim is reproduced only after an execution produces O satisfying T.


A claim is independently verified only when V records an independent route.


A claim is proved only through an appropriate derivational or formal proof obligation.


END
